## 별도 재시도와 원인

실패 작업 6837에 대해 기존 재시도 API를 **한 번** 호출했다. 같은 회원·대화·멱등키로 새 작업 6937(attemptCount=2)이 만들어졌고, 실제 LLM 답변 한 건이 저장됐다. 원래 작업 상태와 답변은 바뀌지 않았다. DB 답변과 HTTP 답변 해시도 일치한다.

현재 OpenAiCompatibleLlmClient는 연결 오류를 LLM-003으로 바꾸고, ChatJobCompletionService는 실패를 DB에 확정한다. Worker는 완료 커밋 뒤 Stream 메시지를 ACK한다. 이번에는 대기 96건도 서버가 없는 동안 빠르게 소비되어 실패로 확정됐으며, 모델 복구를 기다리는 자동 재시도가 없었다. 상태 응답의 retryable은 사용자가 재시도할 수 있다는 뜻이다.

vLLM 누적 성공 지표는 4478에서 재기동 후 0로 초기화됐다. 재기동 전후 수치를 그대로 빼지 않고, 새 프로세스 readiness 이후 별도 재시도에서 성공 호출이 **1건 증가**했는지 확인했다. Worker 지표도 원래 unavailable 100건과 별도 success 1건을 구분한다.
