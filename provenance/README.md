# 결과 출처

이 저장소는 기존 시험 산출물을 모으고 2026-10-26 AWS 재시험·관리자 화면 검증을 추가했습니다. 과거 결과를 이번에 다시 실행한 것처럼 날짜를 바꾸지 않았습니다.

| 자료 | 출처 |
|---|---|
| 로컬 부하·장애 도구 | UBot-BE `tools/perf`, 당시 작업 폴더의 실행기 |
| 로컬 결과 | 2026-10-22~23 보관 원문과 `build/chat-burst-live/final-suite-20261023`의 선별 증거 |
| 이전 AWS 결과 | 2026-10-25 handoff에 보존한 반복 질문·다양한 질문 시험 |
| 최종 AWS 결과 | 2026-10-26 전용 발생기에서 회수한 plan·제출 이벤트·작업 최종 응답, State의 독립 SQL 감사 |
| 통신지도·미응답 | 실제 FE 캡처, 관리자 GET API, 읽기 전용 DB 대조 |
| Discord 알림 | BE PR #274의 수신 기록·원본 캡처, 기존 렌더러와 별도 재검증 |

[files.json](files.json)은 복사 원본과 공개 파일의 해시를 기록합니다. 공통 장애 실행기의 BE 경로·Java 선택 부분은 이 저장소에서 실행할 수 있게 바꿨으며 원본도 `originals/harness.mjs`에 보관했습니다. 기존 세부 보고서의 절대 경로는 당시 실행 환경의 기록입니다.

공개 텍스트의 줄바꿈은 LF로 통일했습니다. `sourceSha256`는 복사 전 원문, `publishedSha256`는 공개 파일을 기준으로 합니다.

부하 결과의 `SUCCEEDED`는 처리 상태입니다. FAQ 일치 정확도·모든 답변의 유용성을 자동 보증하지 않습니다. 설정 변경 전 중간 실패도 최종 실행과 분리해 보관했습니다.
